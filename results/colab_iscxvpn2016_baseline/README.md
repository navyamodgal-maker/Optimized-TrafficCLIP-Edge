# ISCX-VPN2016 Baseline Evaluation

This folder contains the TrafficCLIP evaluation results from Google Colab.

- Test samples: 1,141
- Classes: AIM_Chat, Email, Facebook
- Accuracy: 58.55%
- Macro F1-score: 50.65%
- Weighted F1-score: 62.00%

**Note:** These are baseline results for three classes only. Expanded application-class coverage was not achieved.
